# page-clip

Расширение для Яндекс Браузера (Chrome MV3), которое сохраняет только выбранные блоки веб-страницы в PDF или Markdown. Блоки задаются преднастройками для конкретных сайтов или выбираются мышью прямо на странице. Встроенные преднастройки: «Информация о приёме» и «Информация об исследовании» в личном кабинете SM-Clinic (app.smclinic.ru). Штатный экспорт там теряет дату, клинику, пациента и врача, а результаты исследования отдаются только отдельным PDF.

PDF печатается через стандартный диалог браузера («Сохранить как PDF»), поэтому текст в файле остаётся выделяемым и сторонние библиотеки не нужны. Markdown собирается из тех же блоков и скачивается файлом.

## Установка

1. Откройте `browser://extensions` (в Chrome: `chrome://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/` из этого репозитория.

После изменения файлов нажмите «Обновить» на карточке расширения.

## Использование

1. Откройте нужную страницу и нажмите кнопку расширения.
2. У преднастройки для этой страницы нажмите «PDF» или «MD». Для PDF в диалоге печати выберите «Сохранить как PDF», имя файла уже подставлено (например, `Приём 2026-10-12 Терапевт`). Если на странице у даты нет года и подходит несколько лет, расширение возьмёт год из данных, которые страница сама загрузила с сервера; если не получится, спросит год один раз для этого приёма. На странице исследования расширение само нажмёт «Посмотреть результаты обследования», прочитает текст из PDF и вставит его в сохраняемый документ вместо ссылки на файл (скачивание при этом не происходит).
3. Либо нажмите «Выбрать блоки вручную»: наведите курсор на блок и кликните, чтобы выбрать его, повторный клик снимает выбор. `Alt+↑/↓` или `Alt` с колесом мыши переходят к родительскому или дочернему элементу, Esc отменяет выбор. На панели внизу: «PDF», «Markdown», «Сохранить как преднастройку…».

В настройках расширения можно переименовать и удалить свои преднастройки, поправить их в JSON, сделать копию встроенной, выгрузить всё в JSON и загрузить обратно.

## Если преднастройка не нашла блоки

Сайт мог поменять вёрстку. Сделайте копию преднастройки в настройках и поправьте селекторы в JSON, формат описан в `AGENTS/SPEC.md`. Можно и проще: выберите блоки вручную и сохраните их как новую преднастройку.

## Тесты

Откройте `test/harness.html` в браузере. В заголовке вкладки появится `PASS n/n` или `FAIL k/n`, подробности на самой странице.
