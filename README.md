# page-clip

Расширение для Яндекс Браузера (Chrome MV3), которое сохраняет в PDF только выбранные блоки веб-страницы. Блоки задаются преднастройками для конкретных сайтов или выбираются мышью прямо на странице. Первая встроенная преднастройка: карточка «Информация о приёме» в личном кабинете SM-Clinic (app.smclinic.ru), где штатный экспорт теряет дату, клинику, пациента и врача.

PDF печатается через стандартный диалог браузера («Сохранить как PDF»), поэтому текст в файле остаётся выделяемым и сторонние библиотеки не нужны.

## Установка

1. Откройте `browser://extensions` (в Chrome: `chrome://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/` из этого репозитория.

## Использование

1. Откройте нужную страницу и нажмите кнопку расширения.
2. Выберите преднастройку для этого сайта или «Выбрать блоки вручную».
3. В ручном режиме наведите курсор на блок и кликните, чтобы выбрать его. `Alt+↑/↓` или колесо мыши переходят к родительскому или дочернему элементу. Esc отменяет выбор.
4. В диалоге печати выберите «Сохранить как PDF».

## Проверка синтаксиса

```bash
node --check extension/content.js
```
